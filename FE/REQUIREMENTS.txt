================================================================================
                    WHO'S FREE - PROJECT REQUIREMENTS & DEPENDENCIES
================================================================================
Tài liệu hướng dẫn cài đặt môi trường, danh sách Framework và Thư viện cho các
thành viên / các role khác trong dự án (Backend, QA/Tester, DevOps, PM, v.v.).

Trong hệ sinh thái JavaScript / Node.js, file cấu hình chính là "FE/package.json"
(tương đương với requirements.txt trong Python).

--------------------------------------------------------------------------------
1. YÊU CẦU MÔI TRƯỜNG HỆ THỐNG (SYSTEM PREREQUISITES)
--------------------------------------------------------------------------------
- Node.js: Phiên bản LTS >= 18.x (Khuyên dùng: Node.js 20.x LTS hoặc mới hơn)
  Kiểm tra: node -v
- Trình quản lý gói: npm >= 9.x (Đi kèm với Node.js)
  Kiểm tra: npm -v
- Git: Phiên bản mới nhất
  Kiểm tra: git -v

--------------------------------------------------------------------------------
2. CÁCH CÀI ĐẶT NHANH (QUICK SETUP - KHUYÊN DÙNG)
--------------------------------------------------------------------------------
Mở terminal tại thư mục gốc của dự án, chạy lệnh:

  cd FE
  npm install

Lệnh trên sẽ tự động đọc file package.json và tải toàn bộ các framework, thư viện
được liệt kê bên dưới về thư mục "node_modules".

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
5. CÁC LỆNH CHẠY DỰ ÁN (SCRIPTS)
--------------------------------------------------------------------------------
Chạy trong thư mục FE:

- npm run dev      : Khởi động Development Server (mặc định tại http://localhost:5173/)
- npm run build    : Đóng gói bản Production vào thư mục dist/
- npm run preview  : Chạy thử bản build production trên môi trường local
- npm run lint     : Quét và kiểm tra lỗi cú pháp mã nguồn
- npm run deploy   : Tự động build và deploy lên GitHub Pages
